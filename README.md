# prompt-coach

두서없이 쓴 말을 Claude Code가 알아듣는 요청으로 바꿔 주고, 내 질문이 잘 전달됐는지도 점검해 주는 스킬입니다.

## 설치

Claude Code에서 아래 두 줄을 차례로 입력합니다.

```
/plugin marketplace add MmiInN10/prompt-coach-marketplace
/plugin install prompt-coach@prompt-coach-marketplace
```

설치 후 `/reload-plugins`를 입력하거나 새 세션을 시작합니다.

플러그인 없이 직접 설치하려면 `plugins/prompt-coach/skills/prompt-coach` 폴더를 `~/.claude/skills/prompt-coach`로 복사합니다. 이 경우 호출 이름은 `/prompt-coach`입니다.

## 사용법

```
/prompt-coach:prompt-coach 이 코드 좀 봐줘
```

플러그인으로 설치한 스킬은 이름 앞에 플러그인 이름이 붙어서 위처럼 호출합니다.

## 무엇을 해 주나요

| 기능 | 설명 |
|------|------|
| 요청 정리 | 입력을 `[ROLE] [GOAL] [CONSTRAINTS] [CONTEXT] [QUESTION]`으로 정리해 보여 주고, 승인받은 뒤 실행합니다. 입력에 없는 내용은 지어내지 않고 되묻습니다. |
| 역할 자동 판단 | 코드와 요청을 읽고 "시니어 백엔드 엔지니어, 성능 최적화 중심"처럼 역할과 중점을 정해 밝힙니다. 근거가 약하면 "추측"이라고 표시합니다. |
| 큰 요청 분해 | "전체 로그인 시스템 다 만들어줘" 같은 요청은 분석, 문제 설명, 해결 방법 3단계 계획을 먼저 보여 주고, 승인 후 구현합니다. |
| 긴 로그 처리 | 100줄 이상의 로그는 오류 관련 줄만 추려 `[Relevant Logs Only]`로 분석합니다. 추린 기준과 제외한 줄 수를 함께 알려 줍니다. |
| 전달력 점검 | 내가 쓴 글을 목표, 대상, 맥락, 제약, 초점 5개 항목(5점 만점)으로 평가하고 보완할 점을 알려 줍니다. |
| 학습 기록과 통계 | 점수와 빠뜨린 항목을 기록하고, `/prompt-coach:prompt-coach 통계`로 자주 빠뜨리는 항목과 점수 변화를 보여 줍니다. |

## 출력 예시

입력: `너의 스킬에 대해 짧게 요약해봐`

```
전달력 점검: 3/5 (보통)
- ✓ 목표: "요약해봐"
- ✗ 대상: 어떤 스킬인지 알 수 없음 → "prompt-coach 스킬"처럼 이름 적기
- ✗ 맥락: 요약이 필요한 이유가 없음 → "엑셀 제출용으로"
- ✓ 제약: "짧게"
- ✓ 초점: 요청이 하나

이렇게 물으면 됩니다:
엑셀 제출용으로 prompt-coach 스킬을 세 줄 이내로 요약해줘.
```

## 전달력 점수는 이렇게 매깁니다

| 항목 | 기준 |
|------|------|
| 목표 | 원하는 결과가 드러난다 |
| 대상 | 다룰 파일·코드·문서가 지정돼 있다 |
| 맥락 | 현재 상태, 에러, 환경 중 하나 이상이 적혀 있다 |
| 제약 | 범위, 금지 사항, 형식, 기한 중 하나 이상이 적혀 있다 |
| 초점 | 요청이 하나로 좁혀져 있다 |

항목당 1점이며 4~5점은 "잘 전달됨", 2~3점은 "보통", 0~1점은 "보완 필요"입니다. 평가는 **내가 쓴 글만** 기준으로 합니다. Claude가 파일을 읽어서 알게 된 내용은 점수에 넣지 않아서, 점수가 내 작성 습관을 반영합니다.

## 기록과 개인정보

- 기록은 내 컴퓨터의 `~/.claude/ask-log.jsonl`에만 저장되며 어디로도 전송되지 않습니다.
- 입력은 앞 200자만 저장하고, 토큰·키·비밀번호·이메일 패턴은 `***`로 가립니다.
- 기록을 지우려면 이 파일을 삭제하면 됩니다.
- 기록과 통계에는 Python 3이 필요합니다. 없으면 이 두 기능만 건너뛰고 나머지는 동작합니다.

## 알아 둘 점

- 역할과 중점은 코드와 요청에서 추정한 값입니다. 틀렸다고 말하면 그 부분만 고쳐 다시 보여 줍니다.
- 승인 전에는 파일 수정, 삭제, 커밋 같은 실행을 하지 않습니다.
- 이전에 `ask-marketplace`를 추가한 적이 있다면 `/plugin marketplace remove ask-marketplace`로 지운 뒤 위 설치를 진행합니다.
